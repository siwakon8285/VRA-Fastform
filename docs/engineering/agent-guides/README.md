# Engineering Agent Guides

These documents are reusable engineering guidance for AI agents and humans
working on VRA-Fastform.

They are generic guides, not VRA-specific architecture decisions.

VRA canonical documentation, accepted ADRs, frozen POC specifications, and
explicit user-approved decisions take precedence.

## Guides

- BACKEND.md — backend/service/API engineering
- DATABASE.md — database, persistence, transactions, migrations, data platform
- FRONTEND.md — web/frontend engineering
- MOBILE.md — mobile application engineering

Read all guides relevant to a cross-cutting change.

If a guide conflicts with a higher-authority VRA document, stop and report the
conflict rather than silently changing architecture.
